# A public record per fight state, and the board's own corners

Each fight state has its own public record, with its own corner type: `AnnouncedFight.Fighter` (Elo, multiplier, max stake), `LiveFight.Fighter` (starting and current HP) and `FightRecord.Side` (Elo and multiplier as announced). They look like duplicates, but each is a payload in spec section 9 (`/fights/current`, the SSE events, `/fights` and bet history) holding exactly that state's public data. Merging them into one corner type would mean nullable fields or extra nesting in the public JSON, so we keep them apart. The board likewise keeps its own `Board.Corner` and `Board.Contender` rather than reusing the fight records, because they carry the display logic (`shownHp`, `hpPercent`, `odds`) and the board stays one value that the template only renders. The two copy methods in `BoardService` are the accepted cost.
